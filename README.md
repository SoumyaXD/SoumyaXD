## Featured work

### [Sentinel](https://github.com/SoumyaXD/Sentinel)
**CVE research and patch-prioritization RAG pipeline**

NVD + OSV.dev → normalization → embeddings → Chroma → retrieval → grounded generation → evaluation → FastAPI → Docker → Render.

- 94.4% correct CVE retrieval
- 94.4% factual accuracy
- 94.4% citation correctness
- 100% trap-question handling
- RAGAS: 94.7% mean faithfulness
- Deterministic evaluation + LLM-as-judge evaluation
- Rate limiting and OpenAI spend controls
- BuildKit secret handling for `NVD_API_KEY`
- LangChain implementation benchmarked against the original pipeline

**[Live Demo](https://sentinel-rag.onrender.com/)**
